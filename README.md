# Data Structures Visualization in Java

A desktop Java application that visually demonstrates common **data structures and their operations**. It is designed as a learning tool for understanding how data structures behave through graphical interaction and animation.

## Features

- Visual representation of common data structures
- Interactive insertion and deletion operations
- User-provided input
- Graphical demonstrations of structure changes
- Standalone executable JAR included
- Java source code included

## Data Structures

The project includes visual components for structures such as:

- Arrays
- Stacks
- Queues
- Linked Lists
- Trees and related structures

## Tech Stack

- **Java**
- **Java Swing / AWT**
- **Data Structures & Algorithms**
- **Object-Oriented Programming**

## Run the Application

### Using the JAR

Make sure Java is installed, then run:

```bash
java -jar Visualization.jar
```

### From Source

Open the Java source under `code/src/` in an IDE such as IntelliJ IDEA, Eclipse, or VS Code with Java support, then run the application's main entry point.

## Learning Goals

This project focuses on making abstract data-structure concepts easier to understand by displaying operations visually rather than only through code.

It can be useful for practicing:

- Stack and queue behavior
- Array operations
- Linked-list traversal and updates
- Tree-based structures
- Algorithmic thinking
